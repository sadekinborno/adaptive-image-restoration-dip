Project Name: Adaptive Image Quality Assessment and Restoration SystemCourse: Digital Image Processing (CSE 4883)Core Constraint: This is strictly a classical Digital Image Processing (DIP) pipeline. DO NOT use any Machine Learning or Deep Learning models (no CNNs, no PyTorch, no TensorFlow) for image processing, restoration, or classification.Architecture Overview:The system acts as a pre-processor for smart waste bins. It mathematically diagnoses image flaws (blur, shadows, noise) and applies targeted spatial/frequency filters to restore structural quality before classification occurs.Tech Stack: Python 3.10+, OpenCV (cv2), NumPy, Scikit-Image (skimage), Docker.Pipeline Phases:Phase 1: Load AI-edited BDWaste images and mathematically apply Gaussian noise, defocus blur, and gamma adjustments.Phase 2: Calculate $\text{Var}(\nabla^2 I)$, global mean intensity, and local patch variance to route the image.Phase 3: Apply targeted filters: Unsharp Masking (blur), CLAHE (shadows), or Median (noise).Phase 4: Run Canny Edge Detection and calculate PSNR & SSIM against the clean AI-edited baselines.Phase 5: Package the pipeline into a lightweight Docker container.
